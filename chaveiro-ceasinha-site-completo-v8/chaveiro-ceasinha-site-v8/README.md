# Chaveiro Ceasinha v11

Site estático pronto para GitHub Pages.

## Publicação
Envie todo o conteúdo desta pasta para a raiz do repositório e habilite Settings > Pages > Deploy from a branch > main / root.

## Catálogo
Os produtos ficam no arquivo `script.js`. Para adicionar montadoras, inclua novos objetos no array `products` e um novo botão de filtro no `index.html`.
